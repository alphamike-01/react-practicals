PRACTICAL 14 CAPSTONE QUICK START

1. Start MongoDB.

2. Backend:
   cd backend
   copy .env.example .env
   npm install
   npm run dev

3. Frontend (new terminal):
   cd frontend
   copy .env.example .env
   npm install
   npm run dev

4. Open the Vite URL, normally:
   http://localhost:5173
